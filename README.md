# Home Billiards Tools Lab

Internal tools sandbox for Home Billiards.

## Version 0.1 goal

Secure login + empty dashboard.

## What this is

A separate learning project for building internal tools infrastructure safely.

## What this is not

This is not the live staff Cue Tracker. Do not connect this project to the Cue Tracker database.

## Basic workflow

- `main` = stable deployed version
- `feature/*` = construction zone
- Build and test features first
- Merge into `main` when stable
- Render deploys from `main`
